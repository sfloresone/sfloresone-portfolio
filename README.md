# sfloresone-portfolio

My personal portfolio, [sflores.one](https://sflores.one). Astro 6 + Tailwind v4, built with Bun and deployed as a static site to Cloudflare Pages (build `bun run build`, output `dist`).

- `bun run dev` · `bun run build` · `bun run preview` · `bun run lint`
- Design and code rules live in `AGENTS.md`.
